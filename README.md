# 🌱 Growth Pomodoro

A cozy pixel-art Pomodoro timer where productivity helps a little plant grow. 🌱🌿🌸

Instead of watching a traditional progress bar, users can visually see their focus progress through the growth of a plant.

## ✨ Features

- ⏱️ Pomodoro countdown timer
- 🌱 Interactive plant growth
- 📈 Visual progress indicator
- 🌿 Multiple plant growth stages
- 🌸 Blooming animation at completion
- ▶️ Start / Pause controls
- 🔄 Reset functionality
- ☀️ Cute pixel-art environment
- 📱 Simple and cozy interface

## 🌱 How It Works

The plant grows as the Pomodoro session progresses:

**Start → Sprout → Leaves → Bloom 🌸**

The goal is to make focused work feel more visual, rewarding, and enjoyable.

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Pixel Art Assets
- Figma / Piskel
- - 🔊 Audio feedback for plant growth
- 🎵 Completion sound when the Pomodoro reaches 00:00

## 🎨 Design

The interface uses a soft pixel-art aesthetic with:

- Sky background
- Clouds and sun
- Pixel-art soil
- Growing plant
- Blooming flower

## 🚀 Project Goal

I wanted to experiment with turning a simple productivity timer into a small visual experience.

Rather than only showing a countdown, the application connects productivity with visible growth.
